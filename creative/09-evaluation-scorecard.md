# Quality and gate scorecard

Score each 1–5; reviewers should attach evidence and screenshots. **No design is selected yet.**

| Metric | Weight | Questions |
|---|---:|---|
| Truth of Darb / artistic originality | 20% | Could this concept belong only to Darb? Is it rooted in original practice? |
| Narrative / emotional intelligence | 15% | Does interaction deepen comprehension rather than fake drama? |
| Artwork, people & culture respect | 15% | Are all credits, consents and sensitive claims accurate? |
| Editorial & archive depth | 15% | Can visitors navigate between programmes, works, people, dates? |
| Utility / contemporary programme access | 10% | Are what's on, apply, visit and contact immediate? |
| Visual system excellence | 10% | Art-directed typography, composition, bilingual rhythm, media quality? |
| Interaction craft, accessibility | 10% | Useful, smooth, reduced motion, keyboard/touch parity? |
| Maintainability and performance | 5% | CMS workflow, sensible payloads, reliable mobile? |

**Minimum before execution**: credible 4+ on truth, ethical stewardship, basic utility and bilingual accessibility (not overridden by average score).

## Research exit checklist
- [x] 21-page PDF identified, metadata collected, original binary provided in local handoff.
- [x] 77 unique PDF objects indexed, local media extraction and page previews available.
- [x] Online case-study source register and awards evidence.
- [x] Working brief, narrative territories, initial IA and stack radar documented.
- [ ] Full 77-image caption/artist/photographer rights annotations confirmed by institution.
- [x] Original 21-page PDF and 77 image assets, 21 page renders, 2 contact sheets and CSV/JSON manifest ingested and merged via [PR #1](https://github.com/omarkhair70-droid/darb/pull/1) on 2 Nov 2026.
- [ ] Current venue status, full staff roles and programme operations confirmed directly.
- [ ] Three real-image narrative prototype boards critiqued by team.
- [ ] Motion and AR/EN mobile experiments run.
- [ ] One direction formally selected; design tokens approved.
- [ ] Browser QA/technical approach, prototype and content gate passed.
- [ ] Site implementation authorized.

This status should never be turned into “ready to build” based only on attractive reference screenshots.
