# Design System research — build the language after picking a story

The design system is **not** a Figma color palette prematurely. It must articulate editorial ethics, type, surfaces, media, behavior, motion, accessibility, bilingual content and publishing rules.

## 01. Identity primitives to investigate
- Mark/icon existing Darb signature; usage permissions and contrast requirements.
- **Scale and structure**: evolving exhibit identity vs stable Darb wayfinding.
- Material and surface: clay, glaze, analogue photography, screenprint/cyanotype, courtyard light; mark each sample's actual source.
- Color: functional foundation for legibility + curated event accents; artwork color autonomy.
- Typography: Arabic display/body pair, Latin display/body pair, numeral conventions and mixed-direction editorial captions.
- Spacing/grid: responsive fluid typographic grid, quiet margins vs high-density archive contexts.

## 02. Components needed in a cultural archive
- Hero with truthful event/artwork provenance; index/utility link.
- Editorial story chapter; museum caption; artist credit; date/location chip.
- Artwork image/gallery/deep zoom; consent & usage attribution.
- “Now / Next / Past” programme listing.
- Archive filters; exhibition page; artist cards; curatorial essay; relation links.
- Residency/opportunity CTA and verified application status.
- Visit/service information, accessibility and official venue states.
- Multilingual contextual navigation, search and language toggle.
- Empty, pending, canceled, not-yet-translated and unavailable image states.
- Staff-facing source/credit audit state in CMS.

## 03. Testable typographic systems
**System A / Documentary editorial:** contemporary Arabic body type + quiet Latin serif/sans contrast, captions matter.
**System B / Experimental publication:** strong modular variable type with motion reserved for headings; gallery framed with neutral UI.
**System C / Open exhibition:** light UI scaffolding; artwork visual system changes per programme, with stable navigation.

No licensed typeface selected and no font files shared without proper license.

## 04. Motion tokens (semantic rather than numbers)
- `still`: content remains stationary; default for reading and credits.
- `enter`: gentle entry into field of view.
- `relation`: one archival element leads to another.
- `focus`: zoom/inspect artifact with visible controls.
- `transition`: authored chapter boundary with optional skip.
- `reduced`: replacement of movement with non-motion state.

Exact easing, duration and physics require prototypes and user testing.

## 05. Design system output gate
- 3 alternative art-direction boards with source citations.
- 2 AR/EN responsive typography studies.
- 5 key templates: home, what’s on, exhibition, artist, story.
- Component inventory, state matrix, image behavior and motion principles.
- Design QA rubric including accessibility and cultural accuracy.
