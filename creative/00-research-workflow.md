# Darb 1718 — Product Truth → Creative R&D → Experience

**Status:** Discovery only. NO frontend implementation; NO chosen hero, palette, font, logo redesign, WebGL stack, or animation framework.

## Omar's creative website workflow, tailored
> **Reality → Brief → Research → Reference decomposition → Identity thesis → IA/Experience architecture → Visual/Motion grammar → Exploration → Browser QA → Production/closure.** The process repeats. The answer must not.

### Stage 00 — Evidence + rights
- Preserve original source file (21-page PDF), 77 extracted image objects, 21 page previews, captions, credits, ownership and artist rights; metadata provenance; link existing primary sources.
- Classify evidence as **A: supplied official material**, **B: first-party public**, **C: reputable independent reportage**, **D: unverified context**, **H: hypothesis**.
- Maintain open questions; ask people about unclear or emotionally charged details rather than invent personal stories.

### Stage 01 — Institutional & audience truth
- Interview founder, programme/cultural producer, artists, local craftspeople and audience only with consent.
- Find actual goals: recruit artists? attract programmes? book workshops? international partners? fundraise? preserve archives? venue booking? prioritize after stakeholder workshop.
- Map audience journeys: local attendee, artist applying, researcher, international curator, donor/partner, press, programme staff.
- Audit visual collection with artist credit and contextual caption. No decorative moodboard made from anonymous archival suffering.

### Stage 02 — External references
Every reference gets **Problem → Material → Creative Decision → Technique → Transferable Principle → What NOT to copy → Darb experiment**. At least one case study must come from the maker/award body rather than design-blog screenshots.

### Stage 03 — Competing creative territories
Make three distinct narrative directions with strengths, ethical concerns and testable interactions:
- **The Living Archive** — people / artworks / time / place remain interconnected.
- **A Space That Moves** — changing physical sites, continuous cultural practice.
- **The Act of Gathering** — collaboration, workshops, screenings, shared authorship.
Choose only after image/source review and client alignment.

### Stage 04 — Content model + IA
Define who updates it, art credits, dates, exhibition status, programme variants, calls deadlines, translation and event/artist relationships. Define navigation and page choreography for every route. No fake data as final content.

### Stage 05 — Visual grammar
Test typography, image crops, contrast, page density, gestures, text tone, collage/print textures, arabic/english directional rhythm, motion pacing, wayfinding and quiet states. Make design tokens **after** territory selection, not beforehand.

### Stage 06 — Technology evaluation
Short experiments answer measurable questions: archive search performance; image deep zoom; bidirectional layout; mobile gallery; low-bandwidth first load; frame-rate and reduced motion; publishing workflow. Framework decision after experiments.

### Stage 07 — Prototypes & critique
1–3 focused prototypes illustrating one idea each. Compare against criteria in [creative quality matrix](09-evaluation-scorecard.md). Usability feedback with different audiences; never confuse exciting scroll with useful discovery.

### Stage 08 — Build gate
Begin code only when: approved story + brief + content schema + prioritized features + 77-image curation + visual direction + interaction rules + accessibility/performance budgets + acceptance checks.

## Explicit anti-patterns
- “Fix the old website first” / choose random hero before finding story.
- Copy a museum's fonts/colors/camera motion or manufacture a sentimental comeback.
- Add 3D by default; lock a tech stack before creative objective.
- Turn images into cards without chronology, artist credits or exhibition attribution.
- Run long intro transitions; trap keyboard users; play audio automatically.
- Market a historic floorplan/current location as operational without confirmation.
- Present interactive conceptual studies as fully delivered installations.

## Research truth is stronger than trends
Source priority: material / people's actual experience → creative thesis → reference *principles* → experience architecture → visual system → optional effects.
